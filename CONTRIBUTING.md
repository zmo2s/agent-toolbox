# Contributing to Agent Toolbox

Thanks for helping improve Agent Toolbox! Small, focused contributions are welcome.

## Before you start

1. Read [README.md](README.md) and any relevant skill's `SKILL.md`.
2. Look for an existing issue or open one to describe the proposed change.
3. For a larger change, discuss the approach in the issue before writing code.

## Make a change

1. Fork the repository and create a descriptive branch from `main`.
2. Keep the PR focused on one skill, bug, or documentation improvement.
3. Add a concrete example when changing skill instructions, and describe expected behavior.
4. Do not include credentials, private data, or secrets in examples or logs.
5. If JavaScript behavior changes, add or update tests and run `npm test`.
6. Check your diff with `git diff --check` before submitting.

## Open a pull request

Describe **what changed**, **why it matters**, and **what you tested**. Link related issues. Note any security-sensitive assumptions or limitations. Be clear when checks were not run.

Be respectful and constructive when reviewing others' work.
